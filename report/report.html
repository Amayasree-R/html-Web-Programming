01 Overview

The aim of this assignment was to design a basic website for the Electronics & Communication Engineering (ECE) department. The page has a coloured header with the department logo, a side menu on the left and the content on the right: a welcome note, programmes, faculty, facilities, an enquiry form and contact details. All content is written in HTML; the colours and the two-column layout come from an external file style.css linked in the head.

02 HTML Document Structure

TagPurpose
<!DOCTYPE html>Declaration (not a tag) that the page is an HTML5 document.
<html>Root element; every other element is inside it.
<head>Metadata: character set, title and the link to the CSS file.
<title>Name shown in the browser tab and in search results.
<body>All visible content of the web page.

03 Headings, Paragraphs & Formatting

Headings <h1>–<h6> show the hierarchy of the content: the department name is <h1>, section titles are <h2> and the menu title is <h3>. Paragraphs are written with <p>. For formatting I used <b> (bold), <i> (italic tagline), <u> (underline) and <abbr>, which shows the full form “National Board of Accreditation” when the mouse is placed over “NBA”.

04 Lists

An unordered list (<ul>) was used for the six subjects, because the order of subjects does not matter. Each subject is a list item <li>. Square bullets were selected with the CSS rule list-style-type: square. The side menu is also an unordered list of links.

Screenshot 2 – Subjects shown as a bulleted list

05 Hyperlinks

Links are made with <a href="...">. The side menu uses links such as href="#staff" that jump to the element with id="staff" on the same page. The contact section links to the college website, IEEE and AICTE; target="_blank" opens them in a new tab. A mailto: link opens the visitor’s e-mail app.

06 Images

The logo is added with the <img> tag, which has no closing tag. src is the file path (here an SVG file in the images folder), alt is the description used by screen readers or when the image cannot load, and width="80" sets the width in pixels (height adjusts automatically).

07 Tables

The faculty list is a table of six members. <thead> holds the heading row and <tbody> holds the data rows. Inside them, <tr> makes a row, <th> a heading cell and <td> a data cell. Alternate rows are shaded using CSS nth-child(even).

Screenshot 3 – Faculty table

08 Forms

The enquiry form uses <form action="#" method="post">. Text, e-mail and phone fields use <input> with types text, email and tel; placeholder shows a hint inside the box and required makes the field compulsory. Course preference is selected with radio buttons sharing the same name, so only one can be chosen. The <button type="submit"> sends the form.

Screenshot 4 – Enquiry form

09 Semantic HTML

Semantic tags tell both the browser and the developer what each part of the page is. Compared to using only <div>, they improve readability, accessibility and search-engine ranking.

ElementMeaningWhere it is used
<header>Top/introductory areaLogo, department name and tagline
<nav>Main navigation linksLeft side menu
<main>Main content of the pageRight-hand content area
<article>Independent, self-contained contentWelcome note of the department
<section>A themed part of the page with a headingProgrammes, Faculty, Facilities, Enquiry, Contact
<address>Contact informationDepartment address, phone and e-mail
<footer>Bottom area of the pageCopyright line

10 Conclusion

The ECE department website shows how the basic HTML elements fit together to make a complete page. Separating the styling into style.css kept the HTML file clean and easy to read. The full source code is uploaded to GitHub.
